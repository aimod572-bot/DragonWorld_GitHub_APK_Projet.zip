DRAGON WORLD — PROJET ANDROID

Ce dossier est un vrai projet Android Studio qui transforme le prototype web en application Android avec WebView.

Pour créer l'APK :
1. Installe Android Studio sur un PC.
2. Ouvre le dossier DragonWorld.
3. Laisse Android Studio télécharger/synchroniser Gradle.
4. Choisis Build > Build APK(s).
5. L'APK sera dans :
   app/build/outputs/apk/debug/app-debug.apk

Le prototype contient :
- menu JOUER
- combat 1 contre 1
- Ryōzen
- rival
- coups
- attaque KI
- transformation Super Saiyan
- saut
- barres de vie et de KI
- commandes tactiles
- écran victoire/défaite

IMPORTANT : ce dossier est prêt à être compilé, mais cet environnement ne possède pas le SDK Android/Gradle nécessaire pour fabriquer directement le fichier .apk ici.
